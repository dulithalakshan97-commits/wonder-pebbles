# Wonder Pebbles 🪨🌱

Automated learning cartoons for toddlers and preschoolers (ages 2–5), published to the
**Wonder Pebbles** YouTube channel ([@WonderPebblesLearning](https://www.youtube.com/@WonderPebblesLearning)).

Every day a GitHub Actions workflow:

1. picks today's episode (rotating **Numbers → Colors/Shapes → ABCs → Science**),
2. writes the script, voices it (Microsoft Edge neural voice via `edge-tts`, free),
3. animates it frame by frame (Pillow + FFmpeg) with Pebble the mascot, captions, music and sound effects,
4. uploads it to YouTube as **private** and **Made for Kids**,
5. logs the episode in `episodes.csv`.

You review the video in YouTube Studio and set it to Public when you're happy with it.

Everything is free: public repo = unlimited Actions minutes, YouTube Data API free quota (≈6 uploads/day),
and all art, music and sound is generated by the code (no copyrighted assets).

## Running it

* **Automatic:** every day at 07:43 Sri Lanka time (`.github/workflows/daily-video.yml`).
* **Manual:** Actions → *Daily Wonder Pebbles video* → *Run workflow*. You can pick an episode number,
  the privacy, or untick *upload* to just render a preview (download it from the run's artifacts).
* **Locally:** `pip install -r requirements.txt` (plus `ffmpeg`), then `python make_video.py --episode 3`.

## Secrets (Settings → Secrets and variables → Actions)

| Secret | What it is |
| --- | --- |
| `YT_CLIENT_ID` | OAuth client ID of the Google Cloud project `wonder-pebbles-uploader` |
| `YT_CLIENT_SECRET` | OAuth client secret |
| `YT_REFRESH_TOKEN` | Refresh token for the Wonder Pebbles channel (scope `youtube.upload`) |

## Adding content

All scripts live in `wonder/content.py`: add counting items, colours, shapes, ABC words or a new science
topic (`SCIENCE` list) and it's automatically part of the rotation. Icons are drawn in `wonder/icons.py`.

## Making uploads public automatically

YouTube locks videos uploaded through unaudited API projects to private. To allow automatic public uploads,
request a [YouTube API audit](https://support.google.com/youtube/contact/yt_api_form), using
`docs/privacy.html` (published at https://dulithalakshan97-commits.github.io/wonder-pebbles/privacy.html).
After approval, change the default `privacy` in the workflow to `public`.
